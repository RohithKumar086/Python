Core Concepts

⚡ Top-Down (Memoization) vs Bottom-Up (Tabulation)

Top-Down (Recursion + Memoization)

Starts at the target answer N and recursively breaks down into subproblems, caching results in a dict or array to avoid recalculation.

  • Uses recursion call stack
  • Intuitive to write from recursive relation
  • Time: O(N), Space: O(N) stack + memo

Bottom-Up (Iterative Tabulation)

Starts at base cases (e.g. dp[0], dp[1]) and fills a 1D/2D table iteratively using loops.

  • No recursion overhead / stack overflow
  • Easy to optimize space (e.g. O(N) → O(1))
  • Time: O(N), Space: O(N) or O(1)
Pattern 1

🪜 1D DP: Climbing Stairs & House Robber

climbing_stairs.py
# LeetCode #70 — Climbing Stairs
# State: dp[i] = number of ways to reach step i
# Transition: dp[i] = dp[i-1] + dp[i-2]

def climb_stairs(n: int) -> int:
    if n <= 2: return n
    prev1, prev2 = 2, 1
    for i in range(3, n + 1):
        curr = prev1 + prev2
        prev2 = prev1
        prev1 = curr
    return prev1

print(climb_stairs(5))  # 8 ways
Pattern 2

🪙 Coin Change (LeetCode #322)

Find minimum coins needed to make amount T. dp[i] = min coins for amount i.

coin_change.py
def coin_change(coins: list, amount: int) -> int:
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0  # Base case: 0 coins for amount 0

    for i in range(1, amount + 1):
        for c in coins:
            if i - c >= 0:
                dp[i] = min(dp[i], dp[i - c] + 1)

    return dp[amount] if dp[amount] != float('inf') else -1

print(coin_change([1, 2, 5], 11))  # 3 coins (5 + 5 + 1)

🔤 Longest Common Subsequence (LCS) (LeetCode #1143)

lcs.py
def longest_common_subsequence(text1: str, text2: str) -> int:
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

    return dp[m][n]

print(longest_common_subsequence("abcde", "ace"))  # 3 ("ace")
