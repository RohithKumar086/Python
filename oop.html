Fundamentals

🏛️ The 4 Pillars of OOP

1. Encapsulation

Bundling data (attributes) and methods that operate on that data into a single class, hiding internal implementation details using private attributes (_private or __private).

2. Abstraction

Hiding complex internal logic behind a simple public interface (e.g. using abstract base classes with abc.ABC).

3. Inheritance

Allowing a child class to inherit attributes and methods from a parent class, promoting code reuse.

4. Polymorphism

Allowing different classes to respond to the same method invocation in their own specific way (method overriding).

💻 Anatomy of a Python Class

class_anatomy.py
class BankAccount:
    # Class attribute (shared by ALL instances)
    bank_name = "Global Tech Bank"

    def __init__(self, owner: str, balance: float = 0.0):
        # Instance attributes (unique to each object)
        self.owner = owner
        self._balance = balance  # Protected attribute (convention)

    # Instance method
    def deposit(self, amount: float):
        if amount > 0:
            self._balance += amount
            print(f"Deposited ${amount:.2f}. New Balance: ${self._balance:.2f}")

    def withdraw(self, amount: float) -> bool:
        if 0 < amount <= self._balance:
            self._balance -= amount
            return True
        return False

    # Property decorator (Getter)
    @property
    def balance(self):
        return self._balance

    # Class method
    @classmethod
    def set_bank_name(cls, name: str):
        cls.bank_name = name

    # Static method (utility function independent of state)
    @staticmethod
    def is_valid_interest_rate(rate: float) -> bool:
        return 0 <= rate <= 15.0

# Usage
acc = BankAccount("Rohith", 1000.0)
acc.deposit(500.0)            # Deposited $500.00. New Balance: $1500.00
print(acc.balance)            # 1500.0 (accessed via @property)
print(BankAccount.bank_name)  # Global Tech Bank

Dunder (double underscore) methods allow custom objects to integrate natively with Python operators and built-in functions.

dunder_methods.py
import heapq

class Student:
    def __init__(self, name: str, gpa: float):
        self.name = name
        self.gpa = gpa

    # __lt__ allows heapq to compare Student objects by GPA!
    def __lt__(self, other):
        return self.gpa > other.gpa  # Higher GPA = Higher Priority

    def __repr__(self):
        return f"Student('{self.name}', {self.gpa})"

students = [
    Student("Alice", 3.5),
    Student("Bob", 3.9),
    Student("Charlie", 3.7)
]

heapq.heapify(students)
print(heapq.heappop(students))  # Student('Bob', 3.9) — Highest GPA popped first!
Classic Interview Design Problem

⚙️ LRU Cache Design (LeetCode #146)

An LRU (Least Recently Used) cache discards the least recently used item when capacity is reached. Implemented using a Hash Map + Doubly Linked List in O(1) time!

lru_cache.py
class Node:
    def __init__(self, key: int = 0, val: int = 0):
        self.key = key
        self.val = val
        self.prev = None
        self.next = None

class LRUCache:
    def __init__(self, capacity: int):
        self.cap = capacity
        self.cache = {}  # key → node
        # Dummy head & tail pointers
        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head

    def _remove(self, node: Node):
        p, n = node.prev, node.next
        p.next = n
        n.prev = p

    def _add_to_front(self, node: Node):
        nxt = self.head.next
        self.head.next = node
        node.prev = self.head
        node.next = nxt
        nxt.prev = node

    def get(self, key: int) -> int:
        if key in self.cache:
            node = self.cache[key]
            self._remove(node)
            self._add_to_front(node)  # Move to most recent
            return node.val
        return -1

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            self._remove(self.cache[key])
        new_node = Node(key, value)
        self.cache[key] = new_node
        self._add_to_front(new_node)

        if len(self.cache) > self.cap:
            # Evict least recently used (node before tail)
            lru = self.tail.prev
            self._remove(lru)
            del self.cache[lru.key]

# Usage
lru = LRUCache(2)
lru.put(1, 10)
lru.put(2, 20)
print(lru.get(1))     # 10 (key 1 becomes most recently used)
lru.put(3, 30)        # evicts key 2!
print(lru.get(2))     # -1 (not found)
Must-Know Secrets

💡 Pro-Tips & Interview Things You MUST Know

  1. __slots__ for Memory Optimization: Defining __slots__ = ('val', 'left', 'right') in tree/linked list nodes reduces memory footprint by ~60% by suppressing instance __dict__!
  2. Inheritance MRO (Method Resolution Order): Check standard class inheritance order using ClassName.__mro__ or ClassName.mro().
  3. Composition over Inheritance: Prefer combining smaller objects inside a class (like LRUCache using Node objects) rather than creating deep inheritance hierarchies.
