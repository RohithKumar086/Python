🔄 1. The while Loop — Condition-Based Iteration

A while loop repeatedly executes a block of code as long as its boolean condition evaluates to True. Use a while loop when you do not know in advance how many iterations will be needed.

Anatomy of a while Loop

while_anatomy.py
# 1. INITIALIZATION: set initial counter or state
count = 1

# 2. CONDITION: evaluated BEFORE every iteration
while count <= 5:
    print(f"Count is: {count}")
    # 3. UPDATE / INCREMENT: modify state toward termination
    count += 1

# Output:
# Count is: 1
# Count is: 2
# Count is: 3
# Count is: 4
# Count is: 5
⚠️

Infinite Loop Hazard: If you forget to update the condition variable inside the loop body (e.g. forgetting count += 1), the loop will run forever until interrupted!

Common while Loop Patterns

while_patterns.py
# ─── Pattern 1: Sentinel Loop (Infinite Loop with break) ───
while True:
    user_input = input("Enter positive number (or 'exit' to quit): ")
    if user_input.lower() == "exit":
        print("Exiting loop!")
        break  # Exit immediately
    if not user_input.isdigit():
        print("Invalid input! Try again.")
        continue  # Skip remaining body, prompt again
    print(f"Square: {int(user_input)**2}")

# ─── Pattern 2: Digits Extraction (Mathematical while loop) ───
num = 12345
digit_sum = 0
while num > 0:
    digit = num % 10        # extract last digit
    digit_sum += digit
    num = num // 10          # remove last digit
print(f"Sum of digits: {digit_sum}")  # 15

# ─── Pattern 3: while...else Construct ───
# The 'else' block runs ONLY if the loop finishes naturally (WITHOUT hitting 'break')
attempts = 0
while attempts < 3:
    pwd = "secret"  # simulated input
    if pwd == "secret":
        print("Access Granted!")
        break
    attempts += 1
else:
    print("Account Locked! 3 failed attempts.")

🔁 2. The for Loop — Sequence & Iterable Iteration

Unlike languages like C/Java where for loops are index-based, Python for loops are iterator-based. They iterate over elements of any iterable (lists, strings, tuples, dictionaries, sets, ranges, generators).

How Python for Loops Work Under the Hood

When you write for x in iterable:, Python automatically calls iter(iterable) to get an iterator object, and repeatedly calls next() until a StopIteration exception is raised.

under_the_hood.py
nums = [10, 20, 30]

# What 'for x in nums' actually does:
iterator = iter(nums)
while True:
    try:
        item = next(iterator)
        print(item)
    except StopIteration:
        break  # Clean exit when sequence ends

Mastering the range() Function

range() generates an immutable sequence of numbers on-demand (O(1) memory space!).

SyntaxExampleGenerated SequenceDescription
range(stop)range(5)0, 1, 2, 3, 4Starts at 0, stops before stop

# Forward range
for i in range(5):
    print(i, end=" ")  # 0 1 2 3 4
print()

# Step range

    print(i, end=" ")  # 0 2 4 6 8

    print(i, end=" ")  # 5 4 3 2 1
print()

⚡ 4. Advanced Iteration Helpers: enumerate, zip, reversed, sorted

A. enumerate(iterable, start=0)

Generates index and value simultaneously — eliminates the need for manual counter variables like i = 0!

enumerate_demo.py
colors = ["red", "green", "blue"]

# Default start=0
for idx, color in enumerate(colors):
    print(f"Index {idx}: {color}")
# Index 0: red
# Index 1: green
# Index 2: blue

# Custom start=1 (1-based ranking)
for rank, color in enumerate(colors, start=1):
    print(f"Rank #{rank}: {color}")

B. zip(*iterables)

Pairs up elements from two or more sequences in parallel. Stops when the shortest sequence is exhausted.

zip_demo.py
names = ["Alice", "Bob", "Charlie"]
ages = [25, 30, 35]
cities = ["NY", "LA", "Chicago"]

for name, age, city in zip(names, ages, cities):
    print(f"{name} ({age}) lives in {city}")

# Unzipping a list of tuples back into separate lists!
pairs = [(1, 'a'), (2, 'b'), (3, 'c')]
nums, letters = zip(*pairs)
print(nums)     # (1, 2, 3)
print(letters)  # ('a', 'b', 'c')

🧱 5. Nested Loops & 2D Matrix Traversal

A nested loop is a loop inside another loop. The inner loop executes completely for each single iteration of the outer loop.

nested_loops.py
# 1. 2D Matrix Traversal (Rows and Columns)
matrix = [
    [10, 20, 30],
    [40, 50, 60],
    [70, 80, 90]
]

rows = len(matrix)
cols = len(matrix[0])

for r in range(rows):
    for c in range(cols):
        print(f"matrix[{r}][{c}] = {matrix[r][c]}", end="  ")
    print()  # New line per row

# 2. Pattern Printing — Right Triangle
for i in range(1, 6):
    for j in range(i):
        print("*", end="")
    print()
# *
# **
# ***
# ****
# *****

# 3. Breaking Out of Nested Loops (Using Flag or Function Return)
def find_matrix_target(grid, target):
    for r, row in enumerate(grid):
        for c, val in enumerate(row):
            if val == target:
                return (r, c)  # Immediate exit from all nested loops!
    return (-1, -1)

print(find_matrix_target(matrix, 50))  # (1, 1)

🛠️ 6. All Core Operations Performable Using Loops

Here is a complete catalog of data manipulation patterns you can execute using loops:

loop_operations_catalog.py
nums = [12, 5, 8, 19, 3, 14, 7]

# ─── Operation 1: Accumulation (Sum / Product) ───
total_sum = 0
total_product = 1
for n in nums:
    total_sum += n
    total_product *= n

# ─── Operation 2: Linear Search & Extremes (Min / Max) ───
max_val = nums[0]
min_val = nums[0]
for n in nums:
    if n > max_val: max_val = n
    if n < min_val: min_val = n

# ─── Operation 3: Filtering / Selection ───
evens_only = []
for n in nums:
    if n % 2 == 0:
        evens_only.append(n)

# ─── Operation 4: Counting Frequencies (Manual Hash Map) ───
text = "banana"
counts = {}
for char in text:
    if char in counts:
        counts[char] += 1
    else:
        counts[char] = 1
# {'b': 1, 'a': 3, 'n': 2}

# ─── Operation 5: In-Place Reversing with Two Pointers ───
arr = [1, 2, 3, 4, 5]
left, right = 0, len(arr) - 1
while left < right:
    arr[left], arr[right] = arr[right], arr[left]
    left += 1
    right -= 1
print("Reversed arr:", arr)  # [5, 4, 3, 2, 1]

# ─── Operation 6: Flattening a 2D Matrix to 1D ───
grid = [[1, 2], [3, 4], [5, 6]]
flat = []
for row in grid:
    for val in row:
        flat.append(val)
print("Flat list:", flat)  # [1, 2, 3, 4, 5, 6]

# ─── Operation 7: Deduplication (Maintaining Order) ───
dupes = [4, 2, 4, 1, 2, 5]
unique_list = []
seen = set()
for item in dupes:
    if item not in seen:
        seen.add(item)
        unique_list.append(item)
print("Unique list:", unique_list)  # [4, 2, 1, 5]

1. FizzBuzz (LeetCode #412)

fizzbuzz.py
def fizz_buzz(n: int) -> list:
    result = []
    for i in range(1, n + 1):
        if i % 3 == 0 and i % 5 == 0:
            result.append("FizzBuzz")
        elif i % 3 == 0:
            result.append("Fizz")
        elif i % 5 == 0:
            result.append("Buzz")
        else:
            result.append(str(i))
    return result

print(fizz_buzz(15))

2. Move Zeroes to End (LeetCode #283)

move_zeroes.py
def move_zeroes(nums: list) -> None:
    last_non_zero = 0
    for i in range(len(nums)):
        if nums[i] != 0:
            nums[last_non_zero], nums[i] = nums[i], nums[last_non_zero]
            last_non_zero += 1

arr = [0, 1, 0, 3, 12]
move_zeroes(arr)
print("Moved zeroes:", arr)  # [1, 3, 12, 0, 0]
