📈 What is Big O Notation?

Big O notation measures how the runtime or memory requirements of an algorithm grow as the input size (n) grows towards infinity.

NotationNameExample Operation
O(1)ConstantAccess list index, Dict lookup
O(log n)LogarithmicBinary search, BST search
O(n)LinearLoop through list, String search
O(n log n)LinearithmicMerge Sort, Quick Sort (avg), Timsort
O(n²)QuadraticNested loops, Bubble Sort
O(2^n)ExponentialRecursive Fibonacci (naive)
O(n!)FactorialPermutations of a string
Examples

💻 Code Examples of Each Complexity

O(1) — Constant Time

o_1.py
def get_first(arr):
    return arr[0]  # Always 1 operation regardless of arr size

O(log n) — Logarithmic Time

o_logn.py
def binary_search(arr, target):
    low, high = 0, len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target: return mid
        elif arr[mid] < target: low = mid + 1
        else: high = mid - 1
    return -1

O(n) — Linear Time

o_n.py
def sum_list(arr):
    total = 0
    for x in arr:  # Runs n times
        total += x
    return total

O(n²) — Quadratic Time

o_n2.py
def print_pairs(arr):
    for i in arr:       # n times
        for j in arr:   # n times
            print(i, j)  # Total n * n operations
Rules

📜 Big O Simplification Rules

  1. Drop Constants: O(2n) → O(n). O(500) → O(1).
  2. Drop Non-Dominant Terms: O(n² + n) → O(n²). O(n + log n) → O(n).
  3. Different Inputs Get Different Variables: Two separate arrays A and B in sequence → O(a + b). Nested loops over A and B → O(a * b).
